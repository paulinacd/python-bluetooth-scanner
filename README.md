# Python Bluetooth Device Scanner

Python-based Bluetooth scanning tool developed using the Bleak library.

## Features
- Detects nearby Bluetooth devices
- Logs discovered Bluetooth devices
- Monitors Bluetooth activity for networking/security analysis

## Technologies Used
- Python
- Bleak

## Purpose
Created as a networking and cybersecurity project to explore Bluetooth device discovery and monitoring techniques.
